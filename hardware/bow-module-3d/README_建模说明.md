# 小提琴琴弓传感器模块：3D 草稿参考包

本目录是给 3D 建模人员看的**首版结构草案**，对象是装在小提琴弓杆、靠近弓根（frog）区域的可拆卸光学运动传感器模块。它不是可直接加工的生产图。

## 文件

| 文件 | 用途 |
|---|---|
| `bow_sensor_module_4views.svg` | 可缩放的四视图工程示意：等轴测、俯视、侧视、爆炸图；含中文标注和尺寸线 |
| `bow_sensor_module_draft.scad` | 参数化 OpenSCAD 草模；可直接改参数并导出 STL/3MF |
| `bow_sensor_module_dimensions.csv` | 尺寸、单位、状态和来源 |
| `bow_sensor_module_geometry.json` | 供 CAD/脚本读取的坐标约定、零件包络和接口定义 |

## 结构意图

1. 下夹壳固定在弓杆外圆/多边形外形上，上夹壳用两颗横向螺钉锁紧；夹壳必须能拆卸，不能压到弓毛。
2. 传感器 pod 偏置在弓杆一侧，给六线线缆留后出线和应力释放。
3. pod 下表面有光学窗口。窗口面对一条**独立的、平整且有纹理的跟踪参考条**；参考条不是弓的一部分，图中只作为安装概念示出。
4. PCB 与镜头座在 pod 内部，光学窗口到参考表面的工作距离按器件资料先留 `2.2–2.6 mm` 的可调范围。
5. 压力、弓毛接触、弦号和倾角不由 PMW3360 光学器件直接测得；本草模只预留安装空间，不把这些量画成已实现功能。

## 尺寸状态

- **资料确定**：PMW3360 指南给出的推荐工作距离 `Z=2.2–2.6 mm`、首版 PCB 厚度参考 `1.60 mm`、六线定义 `5V_IN/GND/SCLK/MOSI/MISO/NCS`。
- **初始占位**：夹壳、pod、弓杆直径、螺钉孔距和参考条尺寸，是为了让建模者先建立比例关系的建议值，必须拿实际弓杆、镜头和 PCB 实物复测后冻结。
- **未验证**：当前没有实物安装、光学跟踪、跌落/振动、弓毛避让或板级尺寸测量证据；不能据此下单加工。

## 建模坐标

- `X`：沿弓杆长度方向，向弓尖为正。
- `Y`：从弓杆中心指向传感器 pod 外侧为正。
- `Z`：从弓杆/参考条指向 pod 上方为正；光学窗口朝 `-Z`。
- 参考原点：夹壳中心、弓杆中心线与 pod 安装基准面的交汇处。

## 画图顺序

先按实际弓杆测量外形并修改 `BOW_STICK_DIAMETER`；再核对镜头法兰、PCB 孔位和窗口中心；之后调整 pod 偏置、参考条间隙和线缆出口。最后才确定外壳圆角、螺钉规格和装配公差。

## 依据

- 项目文件：`docs/pmw3360_bow_pcb_guide_cn.md`（2026-10-05）。该文件明确说明 PMW3360 只能测相对二维运动，需要近距离纹理表面；不能在空气中直接测自由挥弓速度，也不能直接测弓压、弦号或倾角。
- PMW3360 手册：项目指南引用的 `PMS0058-PMW3360DM-T2QU-DS-R1.50-26092016._20161202173741.pdf`，重点为机械/镜头、电源和时序章节。
