# 曲谱导入格式（固件 3.5.10 / 位流 R54；3.5.11 + R55 同一套格式）

> 曲谱只做**演奏指引**，不会让琴自己发声。GUIDE 页按你导入的事件闪提示，
> 声音永远来自你手上的动作。
>
> **两版差别只在屏幕画什么，文件格式完全一样：**
>
> | 位流 | 尤克里里（lane 4–7） | 小提琴（lane 0–3） |
> |---|---|---|
> | **R54**（当前在用） | 该行上下 3 px 琥珀线 + 最左空弦块（**只有弦，没有品框**） | 照旧画品格框 |
> | R55 | 再加**左手品框**（x 宽度按品算） | 不画 |

## 一、在哪里导入

手机连 WiFi `Tang60K-Music`（密码 `tang60k2026`）→ 浏览器开 `http://192.168.4.1/`
→ 找到「**曲谱（演奏指引，不发声）**」卡片：

| 步骤 | 操作 |
|---|---|
| 1 | 选「乐器」：**小提琴** / **尤克里里**（只影响 MIDI 自动分弦，文本谱不受影响） |
| 2 | 选文件：`.mid` / `.midi` / `.txt` |
| 3 | 填「速度」BPM：**只对 MIDI 有效**（把 MIDI 的 tick 换算成毫秒） |
| 4 | 点「**解析并上传**」—— 进度条走完，日志显示事件数与时长，存进槽位 1（共 4 槽） |
| 5 | 点「**开始指引**」—— 真正下发到 FPGA，屏幕开始提示 |

不想找文件就先点「**生成演示曲谱**」：尤 1→尤 4，每根「空弦 → 第 3 品」两轮。

## 二、文本谱格式（推荐，最好控）

每行 4 个数，**逗号或空格分隔**都行：

```
时间ms, 弦0-7, 音高0-127, 力度0-127
```

| 字段 | 范围 | 含义 |
|---|---|---|
| 时间 | 0 ~ 65000 | 从曲子开头算的**毫秒**，不是小节号 |
| 弦 | 0–7 | **0–3 = 小提琴 1–4 弦**，**4–7 = 尤克里里 1–4 弦** |
| 音高 | 0–127 | MIDI 音高（G3=55、C4=60、A4=69） |
| 力度 | 0–127 | 只影响右侧电平条长度，不影响指引 |

规则细节（都是代码里真实存在的，不是约定）：

- `#` 开头整行注释；空行忽略
- 少于 4 个字段、或第一列不是数字 → **整行丢弃**，不报错
- **同一根弦、30 ms 窗口内**的多个事件只保留**音高最高**的那个
  （FPGA 每个 lane 只有一个音高寄存器）
- 事件按时间自动排序，你不用按顺序写
- 上限 **1365 个事件**（8 KB），超了页面直接报错，不静默截断
- 曲子时长 = 最后一个事件的时间；名字最长 23 字节

### 最小示例

```
# 时间, 弦, 音高, 力度
0,5,60,100
500,5,62,100
1000,6,64,100
```

## 三、音高怎么变成"第几品"（关键）

FPGA 里 `品位 = 音高 − 该弦空弦音高`，钳在 0~16。**所以你要它显示第 3 品，
音高就必须填"该弦空弦 + 3"**，而不是填 3。

尤克里里默认定弦（`REG_TUNE` 默认值）：

| 弦号 | 名称 | 空弦 MIDI | 第 0 品 | 第 1 品 | 第 2 品 | 第 3 品 | 第 5 品 | 第 7 品 |
|---|---|---|---|---|---|---|---|---|
| 4 | 尤 1（G4） | 67 | 67 | 68 | 69 | 70 | 72 | 74 |
| 5 | 尤 2（C4） | 60 | 60 | 61 | 62 | 63 | 65 | 67 |
| 6 | 尤 3（E4） | 64 | 64 | 65 | 66 | 67 | 69 | 71 |
| 7 | 尤 4（A4） | 69 | 69 | 70 | 71 | 72 | 74 | 76 |

例：想让屏幕在**尤 2 弦第 3 品**亮框 → 写 `时间,5,63,100`。

⚠️ 音高**低于**该弦空弦时，`品位 = 0`（当成空弦），不会报错但提示是错的 —— 这是最常见的错法。

## 四、MIDI 文件怎么处理

- 浏览器端解析，**按你选的乐器分弦**：
  - 小提琴 → lane 0–3（G3/D4/A4/E5 = 55/62/69/76）
  - 尤克里里 → lane 4–7（G4/C4/E4/A4 = 67/60/64/69）
- 分弦规则：**取"不超过该音高的最高空弦"**；若比所有空弦都低，退回最低那根
- 速度用页面上的 BPM 覆盖，**不读 MIDI 自带的 tempo**（简化实现）
- 一个音轨会被压成"每根弦同时只一个音"，和弦会自动只留最高音

## 五、屏幕会怎么提示（R55）

| 事件 | 屏幕反应 |
|---|---|
| 尤克里里，fret ≥ 1 | 该行上下两条琥珀线（右手弦）+ **一个黄色品格框**（左手品） |
| 尤克里里，fret = 0 | 两条琥珀线 + **琴枕左侧空弦区整块亮**（不画框）+ 屏最左锚点块 |
| 你拨响那根弦 | 框、线、块**一起变绿** |
| 小提琴任何事件 | **不显示**（R55 按需求取消） |

⚠️ 绿色只代表"这根弦在响"。尤克里里 4 根弦没有按品传感
（`i_fret_bus` 只有 4 路，只覆盖小提琴），所以**无法判断品按得对不对**。

## 六、排查

| 现象 | 原因 |
|---|---|
| 点了上传但日志说「没有音符」 | 文本谱每行列数不足 4，或第一列不是数字 |
| 日志说「事件 N 超 FPGA 容量 1365」 | 曲子太长，切短或减少注释性事件 |
| 上传成功但屏幕没动静 | 没点「开始指引」；或曲谱卡选的乐器是**小提琴**（R55 不显示） |
| 有弦线但没有品框 | 该事件 `fret = 0`（音高 = 空弦），空弦不画框是设计 |
| 品框位置比实际低 1 格 | 音高算错：应填「空弦 + 品号」，不是品号本身 |
| 整首都没反应，好帧也不涨 | 那是链路问题，不是曲谱问题 → 看「链路状态」卡的收字节/帧头命中 |
