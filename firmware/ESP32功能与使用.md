# ESP32 手机工作台 + 物理面板：使用说明

对应 **固件 3.5.10**（`main.cpp:127` 的 `kFwVer`）+ **FPGA 位流 R54**。
位流侧真源：`00_首页_最新版本/R53_回退R51_网页优化_20261103/manifest.json`。
面板接线见 `旋转编码器接入说明.md`，烧录见 `README_烧录.md`。

---

## 0. 它管什么、不管什么

**管**：音量、音色倾斜、8 弦定弦、混响/阻尼/尾音、曲谱指引、录音试听、链路诊断、4 路物理旋钮。

**不管**：声音本身。发声全在 FPGA 里，ESP32 只发参数帧。
**也没有换乐器**：8 条物理弦在综合期就固定为「4 弓弦 + 4 拨弦」，改不了。

## 1. 开机四步

1. **烧固件**：双击 `一键烧录.cmd`，或 `python tools\flash_tool.py --all --yes`
2. **烧位流**：Gowin Programmer 烧 `R54_尤克里里指引_20261103/烧录_R54_尤克里里指引_20261103.fs`
   —— **R54 是新位流（尤克里里指引），这次必须与 3.5.9 或更新的固件成对烧**；只有 3.5.1~3.5.9 之间换固件才不用重烧位流
3. **连 WiFi**：手机连 `Tang60K-Music`，密码 `tang60k2026`
4. **开网页**：浏览器进 `http://192.168.4.1/`

顶栏显示绿色 `FW 3.5.10` = 网页连上了 ESP32。
「链路状态」卡的**好帧在涨** = FPGA 也通了（这两个是两件事）。

上电后 USB 串口（115200）会打印实际引脚，用来核对接线：

```
[enc] 4x EC11  A/B/SW = 4/5/13 18/19/21 22/23/25 26/27/32
```

## 2. 物理面板：4 个旋钮，每个 3 个动作

| 旋钮 | 旋转 | 短按（**松手时**生效） | 长按 1.5 s |
|---|---|---|---|
| **ENC1** | 音量 ±2（0~255） | 静音 / 取消静音 | 参数复位 |
| **ENC2** | 音色倾斜 ±2（−100~+100） | 倾斜回中（0 dB） | 参数复位 |
| **ENC3** | **当前弦音高 ±1 半音**（MIDI 24~96） | **换下一根弦** | 参数复位 |
| **ENC4** | 混响湿声 ±4（0~255） | 混响旁路开/关 | 参数复位 |

**短按是"松手"那一刻才算**（3.5.2 改的）。按下沿不发动作，所以不会出现"想长按却先触发一次短按"。

⚠️ **由此带来的唯一注意点**：按下去要**及时松开**。按住超过 1.5 秒就不再是短按，而是**参数复位**。正常点按（<0.3 s）不会碰到。

ENC3 的换弦顺序：琴1 → 琴2 → 琴3 → 琴4 → 尤1 → 尤2 → 尤3 → 尤4 → 琴1 循环。
串口会打印当前选中的是哪根：

```
[enc] tune sel = 2  (violin3)  MIDI 69
```

### 面板到底接好没有：网页上有两行现成的诊断

不用接 USB，打开网页就能看（在「弦与定弦」卡片下面）：

| 显示 | 正常值 | 不正常说明什么 |
|---|---|---|
| **面板累计格数 ENC1/2/3/4** | 转哪个哪个涨 | **四个都不动 = 面板完全没通**（先查 GND）。某一个不动 = 那一路 A/B 线没接好 |
| **按键电平 ENC1/2/3/4** | 静置 **1 / 1 / 1 / 1 ✓ 正常** | 某位是 **0** = 那一路 SW 被拉到地（接错、常闭、或按键卡住）。网页会标红 `✗ 有引脚被拉低` |

这两行是判断"是接线问题还是代码问题"最快的入口，比反复烧固件快得多。

**只想知道短按/长按通不通**，也可以跑：

```powershell
python tools\flash_tool.py --watch-enc
```

它会复位后在 25 秒内实时打印 `[enc]` 日志，并按提示逐路按一遍，最后给出 `✓ 收到 / — 没收到` 的汇总。

**引脚表（3.5.9 定稿，3.5.10 沿用）以你按两个工程网络标签逐根核对的结果为准**，不再有二选一宏：

| 旋钮 | A | B | SW |
|---|---|---|---|
| ENC1（最左，音量） | **18** | **19** | **34** |
| ENC2（音色） | **23** | **25** | **35** |
| ENC3（定弦/换弦） | **26** | **27** | **36** |
| ENC4（最右，混响） | **33** | **32** | **39** |

> ENC4 的 A/B 与转接板符号读出（A=D32/B=D33）相反，按你的实物核对为准 —— 这一处只影响**旋转方向**，
> 反了就把 `encoder_panel.cpp` 的 `DELTA_SIGN` 取反，不影响其它三路。

上电串口会自报当前表：

```
[enc] 引脚表 3.5.9：ENC1 18/19/34  ENC2 23/25/35  ENC3 26/27/36  ENC4 33/32/39
```

上拉：四路 **SW 落在 GPIO34/35/36/39**，这四个脚纯输入、**没有内部上拉**，由转接板 `R1..R4` 上拉到 `ESP_3V3`
（`pinMode(INPUT)` 即可，别自己加电阻）。A/B 八根都是普通脚，走内部上拉。

### 2.6 接线自检：一次判定排线方向（3.5.10）

排线是 1-1 还是 1<->14，文件里查不到，而两种接法下四个旋钮**都能动**，只是物理位置整体倒转。
3.5.10 把 12 个编码器 GPIO 的边沿各自计数，网页多了一张「面板接线自检」卡片。

**用法**：点「清零后监视」→ **只转最左那颗旋钮约 5 格** → 看哪两个数在涨。

| 在涨的脚 | 结论 |
|---|---|
| 18 / 19 | 1<->14 反序排线，当前 `kPins` 正确 |
| 32 / 33 | 1-1 同向排线，整组倒转（改表或换线） |
| 34 | A 与 SW 接反：转被当成按压 |
| 全 0 | 面板没通，先查 GND 与排线到底 |

脚本里等价的一条命令（**走 WiFi，不占串口**）：

```
python tools\flash_tool.py --encprobe
```

前提是电脑连着 `Tang60K-Music` 热点；它读的就是 `/encprobe` 这个端点（`?clr=1` 清零）。


另外 3.5.5 修了一个"看起来像没反应"的真 bug：**静音状态下转 ENC1 音量，原来是从 0 起步**（因为静音把 `gVolTarget` 置 0 了），转一两格只有 0→2，根本听不见。现在改成从静音前的音量起步。同时驱动加了 `swArmed`：如果某一路 SW 上电就是低电平（接错/常闭），**不会再在上电 1.5 秒后自动触发一次参数复位**——那种现象看起来是"参数总被拉回去"。

## 3. 参数复位（长按 1.5 s）

**四个旋钮长按效果完全相同**（3.5.3 起，3.5.2 只有 ENC4 能）。

| 参数 | 复位值 |
|---|---|
| 音量 | 128（= 0 dB），同时解除静音 |
| 音色倾斜 | 0（中点） |
| 8 根定弦 | `[55, 62, 69, 76, 67, 60, 64, 69]`（G3/D4/A4/E5 + G4/C4/E4/A4） |
| 混响 | wet **64** / damp **128** / tail **1** / **bypass = 1（干声）** |
| 当前选中弦 | 回到琴1 |

**不重启、不断 WiFi、不清曲谱进度**，只把演奏参数重发一遍（`doParamReset()`，`main.cpp:244-264`）。
串口确认：`[enc] PARAM RESET -> vol=128 tilt=0 tune=std fx=bypass`

注意复位后**混响会回到旁路（干声）**。如果之前开着混响，复位后听起来会"变干"，这是预期行为。

## 4. 网页六张卡片

| 卡片 | 能做什么 | 注意 |
|---|---|---|
| **链路状态** | 只读诊断：FPGA / 好帧 / 坏帧 / 收字节 / 收字节每秒 / RX 空闲电平 / CRC错 / 帧头命中 / LEN错 / loop心跳 / 前 8 字节 | 判读见 §7 |
| **音量与音色** | 音量 0~255（128=0 dB）；音色倾斜 −100~+100（**±12 dB**）；静音按钮 | 音量走软斜坡，不会爆音；有硬件回读，显示 `✓ 与滑杆一致` 才说明帧真到了 FPGA |
| **弦与定弦** | 选 8 根弦之一；填 MIDI 号（24~96）点「写入」；−半音 / +半音 / 标准音；8 弦一览 | 改完立刻生效，GUIDE 页指法框按新定弦重算 |
| **混响 / 阻尼 / 尾音** | 湿声 0~255、阻尼 0~255、尾音 0~3、旁路/启用混响 | **默认是旁路（干声）** |
| **曲谱（演奏指引）** | 选 .mid/.txt → 解析并上传 → 开始指引 / 暂停 / 停止 | **只闪屏幕指法框，不让琴发声**；演奏仍靠你自己 |
| **录音试听** | 录 2 秒 / 试听（WAV） | 12.2 kHz / 8 bit，取自 DAC 输出（随音量变）；**录制中别拖参数** |

## 5. 旋钮和网页是同一套变量

不是两套状态各自记。旋钮改的是 `gVolume / gTilt / gTune[] / gWet / gBypass`，网页改的也是这些。

- 网页 **20 Hz** 推送状态，所以转旋钮后手机滑块会跟着动（约 50 ms 延迟）
- **3.5.4 起连定弦数字也跟着动**：state 里新增 `tn`（8 条 lane 的定弦值）。3.5.3 只推 `tsel`（当前弦号），所以转 ENC3 时网页音高数字不动、看着像"控制失败" —— 那是显示问题，不是旋钮没生效
- **你正在拖的那条滑块不会被旋钮覆盖**（`web_ui.h:231` 用 `document.activeElement` 判断）
- **面板 ENC3 换弦会让网页自动跟随**（`pushState` 里有 `tsel` 字段），不会出现面板在琴3、网页还在琴1 的分叉

## 6. "按了没反应"先看这三条

**1. 混响拖了没效果**
默认 **bypass = 1（旁路/干声）**。先按一下 **ENC4** 或点网页「启用混响」，湿声才有意义。这是最常见的一条。

**2. 音色倾斜感觉不明显**
- 位流必须是 R48 以后（±12 dB）。配 R40（±6 dB）也能调，但听感弱、网页显示的量程对不上。
- 混响开着会掩盖音色判断，网页会显示红字提醒 —— 先切回「旁路（干声）」。

**3. 录音提示 `no audio`**
位流没开通录音（`LINK_PCM_TAP=0`）。R40 及以后都有；R36 及更早没有。

**另外两个"本来就没有"的功能**：换乐器（综合期固定）、动态选弦控制（R53 明确不做）。

## 7. 链路不通怎么读（按顺序，六步）

卡片上有 10 多个数，**从"最原始"往"最解析"一层层看**：

| 步 | 看什么 | 现象 | 结论 |
|---|---|---|---|
| 1 | **RX 空闲电平** | 恒 **0** | 引脚被拉到地：接错到 GND / 对地短路。UART 空闲必须是高 |
| 2 | **收字节/秒** | ≈ **23000**/s | 线被恒定低电平占着（UART 每 10 位时隙判一次帧错塞 0x00）。**接错线**的特征值 |
| 3 | **收字节** | 一直 **0** | 物理层完全没通：TX 线（GPIO17→E14）、共地、FPGA 没在发 |
| 4 | **帧头命中** | 收字节在涨但它 = 0 | 有字节但同步不上帧：波特率不对（应 230400）、线太长受干扰 |
| 5 | **LEN错 / CRC错** | 在涨 | 帧头对了但长度/校验坏：波特率偏差、干扰、某根线虚接 |
| 6 | **好帧** | 在涨 | 链路正常。若参数没反应，说明该功能被位流开关关掉了 |

**最硬的证据是「前 8 字节」**：`A5 5A 90 …` = 真在回合法帧；`（一个字节都没收到）` = 零字节；`FF` = 悬空被上拉；`00` = 被拉低。

也可以不打开网页，直接跑：

```powershell
python tools\flash_tool.py --diag
```

## 8. 曲谱 = 演奏指引，不是自动播放

- 上传后点「开始指引」。**R55 起只有尤克里里会显示指引**：
  - **左手品**：目标品格框（黄，闪烁），空弦画成琴枕左侧的实心块
  - **右手弦**：该行上下两条琥珀提示线 + 最左空弦块
  - 那根弦真的响了 → 框和线**一起变绿**
  - ⚠️ 尤克里里 4 根弦**没有按品传感**（`i_fret_bus` 只有 4 路），
    所以绿色只代表"这根弦在响"，**不代表品按对了**
- **小提琴曲谱不再显示任何指引**（R55 按需求取消）：照常能上传、照常写进槽位，
  只是屏幕上不画框。要做小提琴曲子看指引，暂时没有这个功能
- **琴不会自己响**，声音仍然完全由你手上的动作决定
- 曲谱卡片顶部先选**乐器**（只影响 MIDI 自动分弦）：
  - **小提琴**：MIDI 分到 lane 0-3（G3/D4/A4/E5）
  - **尤克里里**：MIDI 分到 lane 4-7（G4/C4/E4/A4）
- 文本谱每行：`时间ms,弦0-7,音高0-127,力度0-127`（0-3 = 琴 1-4 弦，4-7 = 尤 1-4 弦）
  · **音高要填「空弦 + 品号」**，不是填品号：尤 2 弦（C4=60）第 3 品 → 填 63
  · 完整格式、字段范围、分弦规则、常见错法见 `docs/曲谱导入格式.md`
  · 现成示例：`docs/曲谱示例_小星星_尤克里里.txt`、`docs/曲谱示例_尤克里里音阶.txt`（0→12 品逐格）
- **「生成演示曲谱」**：不选文件，一键生成尤 1→尤 4 的演示 —— 每根先「空弦」再「第 3 品」，
  每步 0.9 s、两轮。空弦那步只看弦线，第 3 品那步会多出品格框，用来验证整条链路
- 同弦同一时刻只保留最高音（FPGA 每个 lane 只有一个音高寄存器）
- 目标框保留到下一次事件或停止，不会因为曲谱暂停而消失
